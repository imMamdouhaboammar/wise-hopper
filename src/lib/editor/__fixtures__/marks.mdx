# التنسيقات الخطية المضمنة

تتضمن هذه الفقرة نصوصاً **غامقة ومؤكدة**، ونصوصاً *مائلة بنبرة خاصة*، ونصوصاً ~~مشطوبة للتصحيح~~، ورموز برمجية مضمنة مثل `const x = 42;` داخل السطر.

كما تتضمن روابط تشعبية مثل [رابط المقال الرئيسي](https://wise-hopper.com) ورابط [صفحة الكاتب الرسمية](https://github.com/imMamdouhaboammar "الملف الشخصي").

الجمع بين العلامات: **[رابط غامق فائق الأهمية](https://example.com)** و *[رابط مائل](https://example.com)*.
