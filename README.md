# وايز هوبر (Wise Hopper) — منصة النشر التحريري العربي المستقل

منصة نشر شخصية متكاملة مصممة باللغة العربية أولاً (Arabic-First) لتمكين الكاتب والمؤلف المستقل من الكتابة في استوديو تحريري متقدم بنظام MDX، وتوليد ثلاث مشتقات رقمية حتمية ومتطابقة دون أدنى انحراف للمحتوى (Zero Content Drift)، مع إدارة احترافية للنشرات البريدية وحماية صارمة على مستوى الخادم للمقالات المدفوعة.

---

## المعمارية والمكونات الأساسية

### 1. خط النشر الحتمي الموحد (The 3-Derivative Pipeline)
يكتب الكاتب المقال مرة واحدة بصيغة MDX، وتقوم منظومة المعالجة النحوية التجريدية (Unified AST Compiler) بتوليد 3 مشتقات ذرية متزامنة:
* **Rich HTML (`/articles/[slug]`)**: مقال تفاعلي مخدّم على الخادم (RSC) يحتوي على التنبيهات المخصصة، الرسوم البيانية (Mermaid)، والصور مع الشروح.
* **Normalized CommonMark Markdown (`/content/[slug].md`)**: وثيقة ماركداون معيارية تحول المكونات المخصصة إلى كتل متوافقة مع محركات الأرشفة والباحثين.
* **Clean UTF-8 Plain Text (`/content/[slug].txt`)**: نص نقي مجرد من وسوم التنسيق يحفظ الهيكل، العناوين، والوصف النصي الدقيق للمخططات والرسوم.
* **توجيه محركات البحث (Canonical & Robots)**: الرابط الأساسي هو دائماً صفحة HTML، بينما تحمل روابط `.md` و `.txt` ترويسة `X-Robots-Tag: noindex, follow` لمنع المنافسة التكرارية في الأرشفة.

### 2. التصميم البصري وتجربة المستخدم العربية (Editorial Arabic UX)
* **لوحة الألوان التحريرية الهادئة**:
  * الأبيض النقي: `#FFFFFF`
  * البنفسجي الأساسي: `#7054D4`
  * الخزامى (Lavender): `#F0EAFF`
  * الخزامى الفاتح: `#F8F6FF`
  * الحبر الأساسي: `#242035`
  * الحبر الثانوي: `#706B80`
* **الطباعة**: خط `IBM Plex Sans Arabic` بمقروئية مدروسة (`line-height: 1.85` و `max-inline-size: 68ch`).
* **الاتجاه**: اتجاه عربي أصيل (`dir="rtl"`) معتمد حصرياً على الخصائص المنطقية (CSS Logical Properties) مثل `margin-inline` و `border-inline-start`، مع عزل الشفرات البرمجية والأرقام والروابط في حاويات LTR معزولة طبيعياً (`unicode-bidi: isolate`).
* **شريط تقدم القراءة وفهرس المحتويات**: شريط دقيق أعلى الصفحة، وفهرس محتويات (Table of Contents) تفاعلي يتابع حركة القارئ على العناوين (`IntersectionObserver`).

### 3. استوديو النشر المتقدم (MDX Publishing Studio)
* مساحة عمل خاصة بالمالك (`/studio`):
  * أوضاع العرض: محرر منقسم متزامن، محرر المصدر النقي، ومعاينة حية، مع وضع الكتابة المركّز (Distraction-Free).
  * شريط إدراج الكتل الآمنة: `Callout`، `Figure`، `PullQuote`، `Mermaid`، `CodeBlock`، و `Table`.
  * الحفظ التلقائي الذكي (Debounced Autosave) مع مؤشرات حالة الحفظ المرئية.
  * سجل المراجعات اللاتزامني وإمكانية الاسترجاع بنقرة واحدة.
  * لوحة فحص السيو والمقروئية اللحظية (SEO Audit Panel): تفحص طول العناوين، الوصف التعريفي، نصوص الصور البديلة، وتحسب عدد الكلمات ووقت القراءة التقديري.
  * النشر الذري: تدقيق أمان المحتوى ورفض أي وسوم خبيثة `<script>` أو أحداث برمجية غير معتمدة.

### 4. حماية المحتوى المدفوع والاشتراكات (Paywall & Zero Leakage)
* نوعان من المحتوى:
  * **مجاني (FREE)**: متاح للقراءة والتنزيل لكافة الزوار.
  * **حصري (PREMIUM)**: مقفل على مستوى الخادم. الزائر غير المشترك يستلم فقط أول فقرتين تمهيديتين متبوعة ببطاقة الاشتراك، بينما يُحجب النص الكامل بصرياً وبرمجياً عن حزم Next.js Server Components وملفات المشتقات `.md` و `.txt`.
* **معمارية الدفع المرنة (Pluggable Billing Engine)**:
  * واجهة برمجية موحدة `PaymentProviderAdapter`.
  * محول افتراضي مدمج `SimulatedBillingProvider` يدعم التوقيع الرقمي HMAC-SHA256، المحاكاة الكاملة للجلسات، الإلغاء، والتجديد.
  * موصلات جاهزة لمزودي الخدمة: **Lemon Squeezy** (Merchant of Record عالمي)، **Paymob** (الشرق الأوسط والخليج ومصر)، و**Stripe**.

### 5. النشرة البريدية الاحترافية (Newsletter Subsystem)
* اشتراك مباشر دون الحاجة لإنشاء حساب قارئ.
* تأكيد اشتراك مزدوج (Double Opt-In) مع رموز أمان عشوائية تشفيرية تنتهي خلال 24 ساعة.
* تخصيص تفضيلات المواضيع حسب اهتمام القارئ.
* تكامل مع Resend لإرسال الرسائل المعاملاتية وحملات النشرة، مع وضع المحاكاة الآمن (Sandbox Mode) عند غياب المفاتيح.
* قوالب بريد تفاعلية متجاوبة ومصممة بالاتجاه العربي (RTL React Email Templates).

### 6. السيو التقني وموجزات الذكاء الاصطناعي (SEO, GEO, AIO & AEO)
* بيانات منظمة دقيقة (JSON-LD) تشمل مخططات `WebSite`، `Person`، `BreadcrumbList`، ومخطط `BlogPosting` متوافق مع معايير جدران الدفع (Paywall Schema) لمحركات البحث.
* موجزات إخبارية ديناميكية:
  * `/rss.xml` (RSS 2.0 Feed مع لغة عربية مخصصة)
  * `/atom.xml` (Atom 1.0 Feed)
  * `/sitemap.xml` (خريطة الموقع المحدثة ذاتياً)
  * `/robots.txt` (سياسات الزحف المعيارية)
  * `/llms.txt` (فهرس مخصص للوكلاء والنماذج اللغوية)

## التشغيل والتطوير المحلي

### المتطلبات
* **Bun**: الإصدار 1.2+ (إلزامي وفق سياسات المشروع).

### 1. تثبيت الحزم
```bash
bun install
```

### 2. المتغيرات البيئية
انسخ ملف الإعدادات النموذجي:
```bash
cp .env.example .env.local
```

### 3. تشغيل الاختبارات المؤتمتة (Vitest)
```bash
# تشغيل كامل حزمة الاختبارات (48 اختباراً في 9 ملفات)
bun run test
```

### 4. البناء والتحقق من سلامة الإنتاج
```bash
bun run build
```

### 5. تشغيل خادم التطوير
```bash
bun run dev
```
افتح المتصفح على: `http://localhost:3000`

## قواعد البيانات والتكاملات الخارجية

### قاعدة بيانات Supabase PostgreSQL
* ملفات الهجرة المعمارية تقع في: `supabase/migrations/20260925000000_init_schema.sql`
  * تتضمن دوال تطبيع الحروف العربية (`normalize_arabic`).
  * فهارس ثلاثية المقاطع (Trigram Indexes عبر `pg_trgm`) للبحث السريع.
  * سياسات أمان مستوى الصفوف (Row Level Security - RLS).
* بيانات البداية النموذجية (Seed Data) تقع في: `supabase/seed.sql`

### إعدادات توثيق النطاق للنشرة البريدية (Resend)
عند الانتقال للإنتاج، يتطلب نطاقك إضافة السجلات التالية في مزود DNS:
* **DKIM (CNAME)**: يتم توليده من لوحة تحكم Resend.
* **SPF (TXT)**: `v=spf1 include:amazonses.com ~all`
* **DMARC (TXT)**: `v=DMARC1; p=quarantine; pct=100; rua=mailto:dmarc@yourdomain.com`
